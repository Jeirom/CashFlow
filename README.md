## Описание

**ДиДиСи** — это удобный веб-сервис, который позволяет пользователям отслеживать свои банковские операции в режиме реального времени. Проект создан для повышения финансовой грамотности и контроля личных расходов.

---

## Возможности

- Просмотр истории банковских операций
- Фильтрация и поиск по операциям
- Категоризация расходов и доходов
- Безопасное хранение и обработка данных

## Установка зависимостей

```
git clone https://github.com/Jeirom/cashflow.git
cd didisi
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
```

## Настройка базы данных
1. Создайте базу данных PostgreSQL:

# createdb didisi_db

2. Настройте переменные окружения: Создайте файл .env в корне проекта и добавьте:

# DATABASE_URL=postgresql://username:password@localhost:5432/didisi_db

# SECRET_KEY=your_secret_key

3. Примените миграции:

# python manage.py migrate

Запуск веб-сервиса

# Для FastAPI/Flask:
uvicorn app.main:app --reload

# Для Django:

python manage.py runserver
Веб-сервис будет доступен по адресу: http://localhost:8000

Использование
После запуска сервера перейдите по ссылке http://127.0.0.1:8000/ и пройдите регистрацию для пользования сервисом.
Либо создайте суперпользователя командой в терминале:

# python manage.py csu

После этого вы сможете войти в сервис с правами администратора.
